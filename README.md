# SiteTest

Landing page for La Piccola Cucina Italiana, an Italian restaurant concept in
Coimbra, Portugal.

## Stack

- React
- Vite
- Tailwind CSS
- Supabase client

## Run locally

```bash
npm install
npm run dev
```

Cria um ficheiro `.env` a partir de `.env.example` e adiciona os valores do
Supabase:

```bash
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

O formulário de reservas grava numa tabela Supabase chamada `reservations`.
Colunas recomendadas:

```sql
create table reservations (
  id bigint generated by default as identity primary key,
  name text not null,
  email text not null,
  phone text not null,
  date date not null,
  time time not null,
  number_of_guests integer not null,
  created_at timestamp with time zone default now()
);
```

Se ativares Row Level Security, adiciona uma policy de insert para permitir que
visitantes enviem reservas:

```sql
alter table reservations enable row level security;

create policy "Allow public reservation inserts"
on reservations
for insert
to anon
with check (true);
```

## Build

```bash
npm run build
```
